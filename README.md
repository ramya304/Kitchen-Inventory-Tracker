# Kitchen Stock Manager 🍳

## About
This is a small Python project I built while learning Python through freeCodeCamp.

It helps track kitchen ingredients like eggs, flour, and sugar. It also checks egg availability and updates the stock when an egg is used.

## What I Learned
- Python functions
- Variables and conditional statements
- Function parameters and return values
- F-strings and print statements

## How to Run
Run `main.py` using Python 3.
